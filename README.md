# Collect · 对话式抖音文稿整理 Skill

### 把账号交给助手，把作品整理成文稿。

输入抖音主页、点赞门槛与整理要求，由支持本地工具的助手完成作品筛选、口播与字幕校对，以及文稿导出。所有操作通过对话完成，无需打开工作台。

**根目录标准 SKILL.md · 多账号 · 自定义门槛 · 字幕与口播交叉校对 · 自定义排版 · 本地文稿**

[下载完整 Skill](https://github.com/evelyn07lg-hub/collect-douyin-skill/archive/refs/heads/main.zip) · [技能入口](SKILL.md) · [使用方法](#开始使用)

## 开始使用

把以下内容发给你使用的助手：

> 请下载并安装这个 Skill：https://github.com/evelyn07lg-hub/collect-douyin-skill 。保留完整仓库，读取根目录 SKILL.md，先检测当前环境是否支持运行，安装后先显示首次使用总览，提示我可以提供主页、点赞门槛、日期范围、已有文档、格式要求和参考稿，再按我的需求操作。不要启动桌面工作台。

安装后，助手首次读取 Skill 时会给出使用总览；你不必填写所有项目，也可以只发主页，其余使用默认值。若安装器仅下载了文件，发一句“开始使用 Collect，给我总览”即可。

安装后继续说：

> 帮我整理这个抖音主页：[粘贴主页链接]。收录不少于500赞的作品，结合视频字幕和口播校对，补好标点，按账号生成文档。

你也可以一次说明完整条件：

> 整理这三个账号近两个月严格超过1000赞的作品。账号标题另起一页，正文五号，每篇留出间距。我有一份参考稿和旧文档，请结合参考稿校对，再续写到旧文档的新副本里。

第一次运行，助手会检查 Python、依赖、模型和浏览器。已有兼容环境直接复用，缺少时才准备；模型首次下载可能较慢。抖音登录和验证由你在浏览器自行完成，不需要向助手发送密码。

## 安装前，确认助手有这些能力

这是包含脚本的真正 Skill：仓库根目录直接提供 [`SKILL.md`](SKILL.md)，同时包含完整运行代码。**Skill 格式通用，不代表每个聊天入口都具备本地执行权限。**

| 你使用的环境 | 使用方式 |
| --- | --- |
| 支持安装 Skill、执行 Python 和操作可见浏览器的助手 | 安装完整仓库，按 SKILL.md 执行 |
| 能下载代码和运行本地工具，但不自动发现 Skill 的助手 | 让它读取根目录 SKILL.md，再按流程调用脚本 |
| Codex 等具备本地工具的环境 | 使用自带的技能安装能力安装仓库根目录，保留 scripts、src 和配置模板 |
| 豆包、DeepSeek 等普通网页/手机聊天入口 | 仅发送链接不能获得本地采集能力；需要支持本地工具的客户端或接入环境 |
| 没有浏览器或执行工具，但支持上传文件 | 可在宿主已有能力内处理你上传的原视频、字幕和参考稿；不能自动扫描主页 |

若助手提示没有权限、没有 Python 或没有浏览器，应按实际缺失条件准备环境，不能把这些情况当作“账号没有达标作品”。安装位置由宿主技能机制决定，**仓库根目录就是 Skill 目录，无需寻找隐藏子目录。**

## 能为你整理什么

- **按条件筛选**：多账号、自定义点赞门槛，支持“不少于”与“严格超过”，可按指定日期范围整理。
- **按主页归属收录**：共创作品只要已核验出现在目标主页，就归入该账号，不因详情页主作者不同而遗漏。
- **校对完整正文**：结合作者画面字幕、实际口播和可选参考稿，修正常见识别错误、补充标点并自然分段。
- **兼顾图文与无口播作品**：图文可选完整发布文案或图片文字；确认无口播的视频可按完整发布文案收录。
- **延续自己的文稿习惯**：自定义字体、字号、行距、篇间距及账号分页，已有本地文档可续写成新副本。
- **保留来源与处理记录**：区分已完成、缺素材、待校对和未核验，原视频可以补充后继续处理。

## 运行环境与成果

推荐 Python 3.12，最低3.10。浏览器支持 Chromium、Chrome 和 Edge；Chromium 可由程序准备，Chrome/Edge 需要本机已安装。实时采集需要用户能看到并操作浏览器，远程无图形环境不能直接保证登录采集。

程序已去除 Windows 工作台依赖，并适配 Windows、macOS 和 Linux 的浏览器与路径处理。**目前完整运行验证在 Windows 完成；macOS/Linux 尚未完成真实设备端到端验证，不承诺所有系统和芯片版本均已验证。**

默认交付 `.docx` 文稿和整理记录，**生成文稿不要求安装 WPS 或 Word，也不会自动打开编辑器**。文稿可用 WPS 等支持 `.docx` 的软件查看。Skill 源码与个人工作目录分开保存，账号、登录会话、稿件不上传公开仓库。

## 共享与更新，由你掌握

没有共享文档也能使用。若需要在线分享，请自行创建或上传金山文档，并**自行开启共享、设置权限**。已有共享文档可由助手按说明配置；云端追加需要单独验证目标、权限、备份与测试副本，填写链接不等于同步成功。

定时更新需要你明确提出，再由助手通过可用的计划任务设置；安装本身不会自动启动后台任务。电脑关机、登录失效或平台验证都会影响运行。

## 关于完整性与校对

采集受平台页面、登录状态、素材可用性及扫描预算影响。未核验或缺素材时保留待处理清单，不能把部分结果称为全部完成。自动校对仍可能有错字，方言、多人对白和专有名词建议重点复核；参考稿不能用于补写视频没有说过的内容。

请仅整理本人创作或已获授权的素材，遵守平台规则与作品权利人的要求。
