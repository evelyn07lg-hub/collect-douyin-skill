# Collect

**抖音文稿整理 · 从作品到文稿，只需一句话**

`主页筛选`　`字幕校对`　`文稿归档`　`自定义排版`

---

### 欢迎使用，选择你的下一步

| 入口 | 你可以做什么 |
| :--- | :--- |
| **01 · 开始整理** | 提供博主主页与点赞门槛，创建新的文稿库 |
| **02 · 续写文档** | 使用已有本地文档，或配置自己的共享文稿 |
| **03 · 校对正文** | 结合视频字幕、实际口播与参考稿，修正文字和标点 |
| **04 · 设置样式** | 调整字体、字号、行距、篇间距与账号分页 |
| **05 · 查看进度** | 查看已有任务、待补素材与已生成文稿 |
| **06 · 使用帮助** | 了解环境准备、浏览器登录和共享方式 |

### 本次整理偏好

**博主主页** `待提供`　 **点赞门槛** `不少于500`　 **日期范围** `全部历史`

**已有文档** `无，新建`　 **排版** `默认样式`　 **参考稿** `可选`　 **更新方式** `仅本次`

---

**回复编号，或直接发主页链接开始。** 也可以直接说：

> 整理这个主页：……。收录超过500赞、最近两个月的作品；宋体五号，每篇留间距，账号另起一页。我有一份旧文档和参考稿。

不必填完所有选项，已提供的信息会直接沿用。共享文档需由你自行开启共享；历史整理会报告实际覆盖范围，不把未完成扫描当作全部完成。
