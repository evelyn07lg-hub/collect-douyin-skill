# 共享文档与定时

默认只生成本地文稿，WPS Office 不是程序依赖。在线共享由用户自行创建文档、开启共享并设置权限。

用户明确需要云端追加时，可在 configure 的 settings 中设置：

```json
{"wps":{"enabled":true,"url":"用户自己的金山共享链接","title":"准确文档标题"}}
```

这只保存目标，不等于已同步。通过浏览器检查目标、账号与编辑权限，保留下载备份，在测试副本完成插入和读回验证后再对用户授权的正式目标追加。现有 WPSWriter 的 test_only、完整性和重复检测必须保留，不得直接改 archived 绕过验证。页面或追加结果不明确时停止，读回确认后再决定，不能盲目重试。云端网页会变化，且 Mac 的完整云端写入尚未经实机验证；失败时交付本地文稿并说明原因。

定时仅在用户明确要求时配置。使用宿主自带计划任务或系统调度，执行同一解释器与 workspace 的 organize。先实测一轮，记录成功/失败及待处理数。Skill 安装不会自动开启后台进程；电脑关机、登录失效、浏览器验证会导致中断。避免多个任务同时使用同一浏览器会话和工作目录。浏览器需要可见用户桌面，不承诺无人值守绕过验证。
